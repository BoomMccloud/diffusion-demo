# Dependency-density results

The dependency-density investigation is complete. Its conclusions are in the
`docs/diffusion_*_findings.md` and `docs/dependency_density_pilot_findings.md`
documents.

Only each run's `summary.json` is tracked in git. The raw per-run artifacts
(per-case rows, logs, remote captures, and script snapshots) remain in the
original working copy and are ignored, so paths in the findings docs that point
below these folders may exist only there.
