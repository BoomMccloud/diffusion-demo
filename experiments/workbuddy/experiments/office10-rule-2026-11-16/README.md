# Office ten-task rule screen

`scores.json` holds the local per-task results. This was a single-trial,
ten-task screen with deterministic scoring only, a 22-turn cap, 8,192 output
tokens per request, and six minutes per rollout. The mean rule score is 52.0%.
It is not the paper's full Office metric. Original full run artifacts are on
the Spark under `~/diffusion-demo/runs/workbuddy-smoke/results/clover-office10-rule/`.
