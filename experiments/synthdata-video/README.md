# Synthetic-data race video

Visualizes results from the synthetic medical data benchmark.

## Contents

`build_data.py` prepares the replay, `replay.html` is the browser replay, and `make_video.py` renders `race.mp4`. This is a visualization of earlier results, not a new benchmark.

Results are exploratory. Check the scripts and saved outputs for the exact
settings and avoid treating a demo as a benchmark leaderboard score.
