# DiffusionGemma business dependency benchmark

This repository compares two pinned model-runtime systems on 12 recognizable
business problems with exactly 48 scored output decisions per case:

- Gemma 4 26B A4B through `llama-cpp-python`.
- DiffusionGemma 26B A4B through the instrumented protocol-v2
  `llama-diffusion-cli`.

The current operational step is to stage the pinned artifacts on an A100, start
the unloaded protocol-v2 worker, and run the no-generation `prepare` gate. See
the [Operator handoff](docs/operator_handoff.md) first. It records the required
prior state, exact pickup point, success gates, resume behavior, and the boundary
between the ready DiffusionGemma path and the unimplemented business AR phase.
`AGENTS.md` remains the authoritative status record, and `bench/README.md` owns
the detailed harness constraints.

## Local checks

```sh
PYTHONDONTWRITEBYTECODE=1 python -B -m unittest discover -s tests -t . -p 'test*.py'
PYTHONDONTWRITEBYTECODE=1 python -B -m bench.business_benchmark self-test --json --output-dir /tmp/business-launch-selftest
PYTHONDONTWRITEBYTECODE=1 python -B bench/dependency_density_bench.py selftest --json
```

These checks are deterministic and offline. They do not establish model quality,
tokenizer comparability on the staged artifacts, or accelerator behavior.

## Archive policy

Keep active implementation, current documentation, extracted evidence, and
maintained tests in their named directories. Put superseded workflows and
duplicate transport bundles under `archive/`, preserving their relative
structure and provenance. Python may generate bytecode during normal operation,
but those caches are disposable and should not be retained in a clean handoff.

**Why:** The 2026-09-08 cleanup found 492 files, of which 409 were saved-result
files and 68 were generated bytecode files. Compressed duplicate bundles accounted
for about 247 MB while an older schedule-demo workflow obscured the active business
screen.

**Guarded by:** `tests/test_repository_layout.py`.

See `archive/README.md` before using any archived material.
