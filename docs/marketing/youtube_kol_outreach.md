# YouTube KOL outreach list

Creators to approach for DiffuSpace: send the brand package and an API key, and
ask for a video. Outreach goes through X and Hugging Face first, then the
business email. Companion to `youtube_launch_study.md`. Drafted messages for
each creator are in `youtube_kol_messages.md`.

## Method

- Checked 2026-10-23. Subscriber counts and last uploads come from each
  channel's page that day.
- X handles come only from the channel's About links or the creator's own
  site. "none found" means neither links one. Nothing is guessed.
- "About email" means YouTube hides the business email behind sign-in and a
  captcha.
- Only Trelis Research and 0xSero link a Hugging Face account, so X and email
  are the main routes.
- Group 1 and 4 X handles were checked by the first research pass. Groups 2
  and 3 were checked one by one against each channel page.
